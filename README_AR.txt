مكتبة الأسئلة – سعي أكاديمي
===========================

هذه حزمة Patch آمنة للمشروع الحالي، وليست نسخة كاملة من المشروع. صممتها لتعديل ملفاتك الموجودة دون استبدال بقية المشروع أو إرجاع ملفات قديمة فوق التحديثات الأحدث في GitHub.

ما الذي ستضيفه؟
----------------
1) رابط «مكتبة الأسئلة» في شريط التنقل.
2) صفحة للطالب تعرض المواد المتاحة، وعند اختيار المادة تظهر الملفات المضافة لها.
3) زر «تحميل الملف» لكل ملف، مع اسم الملف الأصلي.
4) تبويب «مكتبة الأسئلة» في لوحة الأدمن.
5) في الأدمن: اختيار التخصص، ثم المادة التابعة له، ثم كتابة عنوان الملف ورفع PDF أو DOC أو DOCX.
6) يمكن إضافة أكثر من ملف للمادة نفسها؛ ارفع ملفاً بعنوان «أسئلة سنوات ميد»، ثم ارفع الملف الثاني بعنوان «أسئلة سنوات فاينل».
7) عرض الملفات المضافة وحذف أي ملف من لوحة الأدمن.
8) الملفات تبقى في R2 الخاص، ولا يتم جعل الـ bucket عاماً. التنزيل يمر من Worker ويتطلب تسجيل الدخول، والرفع والحذف للأدمن فقط.

التركيب – مهم
-------------
1) افتح مجلد مشروع Saee Academy الحالي على جهازك (نفس المجلد الذي بداخله public و src).
2) فك ضغط هذه الحزمة داخل جذر المشروع نفسه، بجانب مجلدي public و src.
3) شغّل الملف `apply_question_library_patch.bat` بالنقر المزدوج. أو افتح Terminal داخل جذر المشروع وشغّل:

   py apply_question_library_patch.py

   (إن لم يعمل py استخدم: python apply_question_library_patch.py)

4) سيضيف السكربت رابط الصفحة والواجهة وتبويب الأدمن ومسارات API إلى ملفاتك الحالية. لا يستبدل src/entry.py كاملاً؛ يضيف المسارات المطلوبة داخله حتى يحافظ على بقية التحديثات الموجودة لديك.
5) راجع الملفات التي أظهرها السكربت، ثم اعمل Commit/Push على فرع main.
6) تابع GitHub Actions حتى ينجح نشر GitHub Pages ونشر Cloudflare Worker.

قاعدة البيانات وCloudflare
--------------------------
- لا يوجد Migration جديد مطلوب لهذه الإضافة.
- ينشئ Worker جدول question_files تلقائياً عند أول استخدام عبر D1 binding الموجود حالياً، لذلك لا تحتاج إلى تطبيق Migration يدوي أو إنشاء قاعدة بيانات جديدة.
- يستخدم الرفع والتخزين bucket الحالي: saee-academy-media.
- الحد الأقصى لحجم الملف الواحد 50 MB.
- الصيغ المقبولة: PDF و DOC و DOCX.

طريقة الاستخدام بعد النشر
-------------------------
للأدمن:
1) افتح admin.html وسجّل الدخول بحساب الأدمن.
2) افتح تبويب «مكتبة الأسئلة».
3) اختر التخصص، ثم المادة.
4) اكتب عنواناً واضحاً للملف، مثلاً «أسئلة سنوات ميد»، وحدد الملف واضغط «رفع ملف الأسئلة».
5) كرر العملية للملف الثاني بعنوان «أسئلة سنوات فاينل».

للطالب:
1) سجّل الدخول إلى الموقع.
2) اضغط «مكتبة الأسئلة» من شريط التنقل.
3) اختر المادة المطلوبة.
4) اضغط «تحميل الملف» بجانب ملف الميد أو الفاينل.

ملاحظة اختبار
--------------
تم فحص صياغة JavaScript وPython في نسخة الاختبار، وفحص إنشاء جدول D1 والاستعلامات محلياً. الاختبار الفعلي لرفع الملفات وتنزيلها يحتاج إلى نشر Worker ثم تجربة رفع ملف من لوحة الأدمن على حساب Cloudflare الفعلي.
