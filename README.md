# سعي أكاديمي — ملفات الموقع

هذه نسخة من ملفات المصدر لتطبيق سعي أكاديمي. تتضمن واجهة الموقع، خادم API، ومخطط قاعدة البيانات. لا تتضمن المكتبات المثبتة، الملفات المبنية، قاعدة بيانات فعلية، أو قيم أسرار.

## التشغيل داخل Replit
1. فك الضغط أو انسخ الملفات إلى مشروع Replit.
2. شغّل `pnpm install`.
3. أضف إعدادات التشغيل المطلوبة من لوحة Secrets / Environment في Replit، ولا تكتب القيم السرية داخل الملفات:
   - `DATABASE_URL`
   - `CLERK_SECRET_KEY`
   - `CLERK_PUBLISHABLE_KEY`
   - `VITE_CLERK_PUBLISHABLE_KEY`
   - `SAI_ADMIN_EMAIL` (البريد الأساسي الموثق لحساب المشرف)
4. إذا كانت قاعدة البيانات جديدة أو لم يُطبق المخطط، شغّل `pnpm --filter @workspace/db run push`.
5. شغّل المشروع من زر Run في Replit. مفاتيح Clerk الإنتاجية مطلوبة قبل نشر الموقع للمستخدمين.

تضاف الفيديوهات من لوحة الإدارة كرابط HTTPS، بحد أقصى 30 درسًا للمادة. الدفع يتم يدويًا خارج الموقع.
