# سعي أكاديمي

ملفات مصدر الموقع جاهزة للرفع إلى مستودع GitHub بعد فك ضغط هذا الأرشيف. يحتوي المشروع على واجهة الطالب ولوحة المشرف وخادم API ومخطط قاعدة البيانات. لا يحتوي على قاعدة بيانات فعلية أو ملفات اعتماد سرية أو المكتبات المثبتة أو نواتج البناء.

## قبل رفعه إلى GitHub
1. فك ضغط الملف، ثم ارفع **محتوياته** إلى المستودع؛ لا ترفع ملف ZIP كبديل عن ملفات المشروع.
2. احتفظ بملف `.env.example` كقائمة بأسماء الإعدادات فقط. لا تضف قيمًا حقيقية إلى GitHub.
3. أضف القيم المطلوبة في إعدادات Secrets / Environment لدى المنصة التي ستشغّل الموقع.

## إعداد وتشغيل نسخة Replit
1. شغّل `pnpm install`.
2. أضف `DATABASE_URL` ومفاتيح Clerk و`SAI_ADMIN_EMAIL` إلى إعدادات البيئة الآمنة. بريد المشرف يجب أن يكون البريد الأساسي الموثّق لحسابه.
3. إذا كانت قاعدة البيانات جديدة أو لم يُطبق المخطط، شغّل `pnpm --filter @workspace/db run push`.
4. شغّل المشروع من زر Run في Replit.
5. استخدم مفاتيح Clerk الإنتاجية قبل نشره للطلاب.

تضاف الدروس من لوحة المشرف كرابط HTTPS، بحد أقصى 30 درسًا للمادة. الدفع يبقى يدويًا خارج الموقع.
